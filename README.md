# OpenFrontIO-Android

An **unofficial port** of [Open Front](https://openfront.io/) to Android.

## Features

- ✅ **Single-player mode** — Play offline against AI
- ✅ **Saving functionality** — Games are saved locally and can be resumed
- ✅ **Touch-optimized controls** — Designed for mobile gameplay
- ✅ **Full game content** — All maps, units, and mechanics from the browser version

## About

This is a community-driven Android port of the open-source browser-based RTS game Open Front. The original game is playable at [openfront.io](https://openfront.io/).
